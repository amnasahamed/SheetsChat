Marketplace Screenshots Guide

Google Workspace Marketplace requires 3-5 screenshots (1280x800 or 640x400 PNG/JPG). Below are the 5 screenshots to capture.

Use Chrome at 1280x800 resolution. Open DevTools (F12) → toggle device toolbar (Ctrl+Shift+M) → set to 1280x800. Take screenshots with Ctrl+Shift+S → "Capture full size screenshot" or use the OS screenshot tool.

1. Setup Tab

What to show: The SheetsChat sidebar open to the Setup tab, with a provider (e.g., OpenAI) selected in the dropdown, the model dropdown showing available models, and the API key field visible. Fill in some sample values.

File: screenshots/01-setup.png

2. Test Chat Tab

What to show: The Test Chat tab with an active conversation. Type a message like "Hello, what can you help me with?" and show the bot's response. Show the chat bubbles with the configured bot name and color.

File: screenshots/02-test-chat.png

3. Deploy Tab

What to show: The Deploy tab with the embed code displayed and the widget preview visible on the right side. This shows how easy deployment is.

File: screenshots/03-deploy.png

4. Widget on Website

What to show: The chat widget embedded on a sample webpage (can be a simple HTML page). Show the widget opened with a conversation in progress. This demonstrates the end-user experience.

File: screenshots/04-widget.png

5. Knowledge Base Tab

What to show: The Knowledge Base tab with 2-3 entries visible, showing categories, questions, and answers. This highlights the custom knowledge feature.

File: screenshots/05-knowledge-base.png

After Capturing

  1. Save screenshots to docs/screenshots/ in the repo
  2. Upload to Google Workspace Marketplace → Store Listing → Screenshots section
